# Расчёт арендных обязательств (ФСБУ 25)

## Назначение

Механизм повторяет типовую справку-расчёт по аренде в Excel и переносит её результат в баланс через правила дозаполнения. Типовое значение аренды сторнируется, вместо него ставится расчёт по схеме справки-расчёта.

Что типовое заполнение (БП, форма 2025) делает с арендой и что исправляет механизм:

| Строка | Типовое заполнение | После правил (схема справки-расчёта) |
|---|---|---|
| 1520, вписанная строка «Обязательство по аренде» | краткосрочная часть по типовому разделению | неоплаченные начисленные платежи 76.07.2 (кредиторская задолженность) |
| 1550 | аренда не попадает | краткосрочная часть аренды: дисконтированные платежи в пределах 12 месяцев (без уже начисленных) + аванс |
| 1450, слагаемое «Долгосрочная часть обязательства по аренде» | долгосрочная часть по недисконтированному графику через 12 месяцев | дисконтированные платежи позже 12 месяцев |

Итог по договору типовое считает верно (сальдо 76.07). Ошибается разделение: долгосрочную часть типовое берёт по графику без дисконтирования, а при отсрочке оплаты относит в долгосрочную всё обязательство.

## Источники

- проведённые `ПоступлениеВАренду` и последнее действующее `ИзменениеУсловийАренды` на отчётную дату;
- табличная часть `ГрафикПлатежей`: дата, сумма платежа и НДС; ставка дисконтирования документа;
- остатки 76.07.1 и 76.07.2 по договору — для определения порядка оплаты;
- типовой расчёт `РасчетПоказателейБалансаПоОбязательствам.ИсходныеДанныеПоАренднымОбязательствам` — только для сторно типовой долгосрочной части в строке 1450.

## Алгоритм по договору

1. Берутся платежи графика позже отчётной даты, из каждого исключается НДС.
2. Платёж дисконтируется по дням: `СуммаБезНДС / (1 + ГодоваяСтавка)^(Дней / 365)`.
3. Платежи до отчётной даты + 12 месяцев включительно — краткосрочная часть, позже — долгосрочная.
4. Порядок оплаты определяется автоматически на каждую отчётную дату сверкой будущих платежей графика (с НДС) с 76.07.1 и 76.07.2, допуск 1 руб.:
   - **обычный** — график равен 76.07.1;
   - **предоплата** — 76.07.1 больше графика; разница (аванс, без НДС) добавляется в краткосрочную часть;
   - **постоплата** — график больше 76.07.1 ровно на несколько ближайших платежей, и это покрыто кредитом 76.07.2. Эти платежи уже начислены и в аренду не включаются. Вся сумма 76.07.2 показывается как кредиторская задолженность в 1520. Если на 76.07.2 больше, чем ближайших платежей, выдаётся предупреждение о вероятной просрочке;
   - **отсрочка** — превышение графика не совпадает с ближайшими платежами, а 76.07.2 состоит из целого числа одинаковых взносов основного долга. Взнос = (оплаты Дт 76.07.2 − начисленные проценты «Проценты за отсрочку…») / число оплат. Взносы, приходящиеся на платежи ближайших 12 месяцев, но не больше остатка 76.07.2, идут в 1520 как кредиторская задолженность; остальная краткосрочная часть — в 1550;
   - **неоднозначный** — ни один признак не подошёл. График считается целиком, часть 76.07.2, входящая в график, остаётся в аренде, выдаётся предупреждение.

Проценты за отсрочку отличаются от начисления аренды только содержанием проводки («Проценты за отсрочку платежа…»). Если содержание другое или остаток 76.07.2 не делится на взнос, отсрочка не признаётся: вся краткосрочная часть остаётся в 1550 с предупреждением.

## Операнды правил

| Способ расчёта | Значение |
|---|---|
| `Аренда: краткосрочная часть` | краткосрочная часть по схеме справки-расчёта |
| `Аренда: долгосрочная часть` | долгосрочная часть |
| `Аренда: обязательство всего` | сумма двух частей |
| `Аренда: неоплаченные платежи (76.07.2)` | начисленные, но не оплаченные платежи (при отсрочке — взносы основного долга к погашению в 12 месяцев) — кредиторская задолженность |
| `Аренда: долгосрочная часть по типовому расчету` | то, что типовое уже записало в 1450 |
| `Аренда: краткосрочная часть по типовому расчету` | то, что типовое уже записало во вписанную строку 1520 |

## Правила профиля организации

Бухгалтеру в расшифровке видно, что посчитала 1С, что правило сторнировало и какую сумму поставило: каждое правило пишет отдельные строки «− типовое» и «+ наш расчёт». У цели своя формула из одного операнда, и в подписи строки указано, что это за операнд.

| Правило | Операнды | Цели (по порядку) |
|---|---|---|
| Аренда: 1520 — сторно типовой аренды и неоплаченные платежи 76.07.2 | A — неоплаченные платежи 76.07.2; B — краткосрочная часть по типовому расчёту | вписанная 1520 «Обязательство по аренде»: «Уменьшить» `B`, затем «Добавить» `A` |
| Аренда: 1550 — краткосрочная часть по графику | A — краткосрочная часть | стандартная 1550: «Добавить» `A` (типовое аренду в 1550 не кладёт) |
| Аренда: 1450 — долгосрочная часть по графику вместо типовой | A — долгосрочная часть; B — долгосрочная часть по типовому расчёту | стандартная 1450: «Добавить» `A`, «Уменьшить» `B` |

Вид расшифровки вписанной строки «Обязательство по аренде»:

```
+ Краткосрочная часть обязательства по аренде (1С)                    X
− [Аренда] …: Краткосрочная часть аренды по типовому расчету         −X
+ [Аренда] …: Начисленные и неоплаченные арендные платежи (76.07.2)   Y
= Y
```

Контроль сторно: если «Уменьшить» в строке расшифровки (вписанной или прямой) снимает не ту сумму, что записала 1С (расхождение больше 1 руб.), бухгалтер получает сообщение с остатком. Поэтому в правиле 1520 цель «Уменьшить» стоит первой. «Заменить типовое значение» по-прежнему доступно, если отдельные строки не нужны.

Защита: арендный операнд не может «Заменить» стандартную строку баланса целиком. В стандартную строку аренда только добавляется или вычитается, поэтому прочие слагаемые 1450, 1520 и 1550 сохраняются.

Каждая графа (текущая дата, 31 декабря прошлого и позапрошлого года) считается на свою отчётную дату. Профиль аренды стоит подключать к организации с начала позапрошлого года, чтобы сравнительные графы считались теми же правилами.

Копеечные расхождения со справкой-расчётом возможны из-за округления НДС в графике 1С: Excel берёт суммы без НДС напрямую.
