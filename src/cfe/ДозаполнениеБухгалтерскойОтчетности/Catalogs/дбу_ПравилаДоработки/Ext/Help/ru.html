Правила доработки бухгалтерской отчётности

Справочник Правила доработки описывает, как скорректировать типовую бухгалтерскую отчётность по данным учёта: откуда взять сумму (операнды), как её вычислить (формула) и в какие строки отчёта записать результат (цели). Правила входят в профиль доработки организации и применяются при формировании отчёта автоматически.

Карточка правила состоит из трёх частей:

  • Шапка — вид правила, раздел отчёта, формула, приоритет;
  • Операнды — источники сумм из регистра бухгалтерии (счета, сальдо, обороты, отборы СКД);
  • Цели — строки отчётности и действие с показателем (добавить, уменьшить, заменить).

Перед записью нажмите Проверить формулу. Недоступные для выбранного способа расчёта поля операнда на форме блокируются автоматически; при смене способа несовместимые значения очищаются.

Кнопка Пробный расчёт открывает отдельную форму проверки: по текущим (в том числе несохранённым) настройкам правила рассчитываются суммы операндов и итог формулы за выбранный период. По двойному щелчку на строке операнда можно открыть типовой отчёт (ОСВ, анализ счёта и т.п.) с отбором, соответствующим настройке операнда.

Формула правила

В формуле используются идентификаторы операндов — латинские буквы A, B, C… (регистр не важен). Допустимы:

  • арифметика: +, −, *, /, скобки;
  • функции: Мин(…), Макс(…);
  • условие: ?(условие, значение_если_истина, значение_если_ложь).

Примеры:

  • A — одна сумма операнда A;
  • A−B — разность двух операндов (свёртка);
  • Макс(A−B, 0) — только положительная часть разности;
  • ?(A > B, A−B, 0) — условная корректировка.

Кнопка Вставить Макс(,0) подставляет шаблон функции в поле формулы. В колонке Формула цели можно задать выражение, отличное от формулы в шапке (необязательно).

Множитель операнда (1 или −1) — это знак вклада операнда в формулу. Не путать со знаком сальдо (отбор только положительной или отрицательной части сальдо на активно-пассивном счёте).

Свёрнутое и развёрнутое сальдо

Свёрнутое сальдо (СНД, СНК, СКД, СКК) — одна сумма по счёту в целом. Для активно-пассивных счетов можно ограничить знак сальдо: взять только положительную (+) или только отрицательную (−) часть.

Развёрнутое сальдо (СНДР, СНКР, СКДР, СККР) — сумма по развёрнутым остаткам с учётом указанной детализации (видов субконто). Без детализации расчёт идёт по счёту целиком, но логика развёртывания отличается от свёрнутого способа.

Обороты ДО и КО

Укажите счёт и способ ДО или КО. Кор. счёт необязателен: без него берётся оборот по счёту; с кор. счётом — оборот в корреспонденции между двумя счетами. При заполнении кор. счёта поле Детализация очищается и недоступно.

Отбор СКД

Порядок настройки:

  1. Укажите счёт операнда.
  2. Выберите способ Остатки и обороты с отбором.
  3. Нажмите Настроить отбор — откроется форма с полями отбора (организация, период подставляются при расчёте отчёта).
  4. Задайте отборы: субконто, контрагенты, кор. счёт, вид сальдо/оборота и т.д.
  5. После сохранения в колонке «Показатель СКД» появится ссылка на элемент справочника Запросы данных; при необходимости скорректируйте детализацию для расшифровки.

Одинаковые настройки отбора переиспользуются (хранятся по хэшу настроек). Изменение отбора создаёт или обновляет запись в справочнике запросов.

Произвольный запрос

Используется для вида правила Произвольный запрос или когда сумма заранее описана в справочнике Запросы данных. Укажите способ Произвольный запрос и выберите элемент справочника в колонке «Показатель СКД». Счёт и детализация для такого операнда не используются.

Выбор детализации (субконто)

Нажмите в колонке Детализация — откроется форма выбора видов субконто для указанного счёта. Список ограничен субконто, настроенными на счёте в плане счетов. Порядок видов важен для группировки в расшифровке.

Виды субконто с признаком только обороты (например, Статьи движения денежных средств на счёте 50) помечаются в списке как «(только обороты)». Для способов расчёта по сальдо (СНД, СКД, СНДР, СКДР и т.д.) такие виды недоступны — по ним остатки в учёте не ведутся. Для оборотов (ДО, КО) и отбора СКД они доступны.

Перенос между строками

Все цели должны относиться к одному разделу отчёта (задаётся в шапке). Первая строка целей — источник (действие Уменьшить), вторая и следующие — приёмники (действие Добавить). Сумма по формуле уменьшает источник и добавляется к приёмникам согласно настройке движка.

Свёртка счетов

Операнды описывают сальдо или обороты по счетам (например, A — дебиторка, B — кредиторка). Формула A−B или Макс(A−B,0) задаёт величину свёртки. Цели распределяют результат: уменьшение в одних строках баланса, добавление в других. Заполните сторону свёртки, если правило должно учитывать актив/пассив.

Расшифровка

При просмотре отчёта с применёнными доработками по ячейкам с корректировкой доступна расшифровка: показывается вклад с детализацией по операндам правила. Для операндов с детализацией субконто расшифровка может открывать ОСВ с отбором по счёту, субконто и настройкам СКД. Для способов с знаком сальдо в расшифровку попадают только строки с подходящим знаком остатка.

Примеры настройки

Корректировка по сальдо счёта

  • Вид: Корректировка показателя.
  • Операнд A: способ Сальдо на конец (Дт), счёт 62.01.
  • Формула: A.
  • Цель: нужная строка баланса, действие Добавить.

Свёртка взаимных требований

  • Вид: Свёртка счетов.
  • A: СКД по 62.01; B: СКК по 60.01.
  • Формула: Макс(A−B, 0).
  • Цели: уменьшить дебиторку, добавить в нужную строку (или зеркально по пассиву).

Отбор по контрагенту (СКД)

  • Операнд A: счёт 62, способ Остатки и обороты с отбором.
  • «Настроить отбор»: организация, субконто «Контрагенты», нужный контрагент.
  • Детализация: Контрагенты, Договоры — для расшифровки по договорам.

Развёрнутое сальдо по субконто

  • Способ: Сальдо на конец развёрнутое (Дт).
  • Счёт 60.01, детализация: Контрагенты, Договоры.
  • Сумма считается по развёрнутым остаткам с группировкой по указанным субконто.
Проверка и типичные ошибки
  • Формула ссылается на несуществующий операнд — проверьте идентификаторы в таблице операндов.
  • Не указан счёт — для всех способов, кроме «Произвольный запрос», счёт обязателен.
  • Отбор СКД не настроен — для способа «Остатки и обороты с отбором» нажмите «Настроить отбор» после выбора счёта.
  • Перенос: одна цель — для переноса между строками нужно минимум две цели.
  • Строка отчётности из другого раздела — смена раздела в шапке сбрасывает строки в целях; выберите строки заново.
  • Знак сальдо не действует — доступен только для свёрнутых способов (СНД, СНК, СКД, СКК), не для развёрнутых и оборотов.

Правило должно быть активно и входить в профиль доработки, назначенный организации на период отчёта. Порядок применения правил задаётся приоритетом профиля направления и приоритетом самого правила.
